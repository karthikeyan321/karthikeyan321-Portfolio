```

## 🚀 How to Use

### Option 1: Local Development
1. Create a folder called `portfolio`
2. Download all three files (index.html, style.css, script.js)
3. Place them in the same folder
4. Open `index.html` in your browser

### Option 2: Deploy Online (FREE)

#### GitHub Pages
1. Create a GitHub repository named `portfolio`
2. Upload all files to the repository
3. Go to Settings → Pages → Select main branch
4. Your site will be live at: `https://yourusername.github.io/portfolio`

#### Netlify (Easiest)
1. Go to https://netlify.com
2. Sign up with GitHub
3. Drag & drop your portfolio folder
4. Get instant deployment with live URL

#### Vercel
1. Go to https://vercel.com
2. Import your GitHub repository
3. Auto-deployment on every update

```

### Add More Projects
In `index.html`, duplicate a `.project-card` and update:
